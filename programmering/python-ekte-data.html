Programmering / Fysikk 1 og Fysikk 2

Fysikk i Python med ekte data

I stedet for ferdige tall fra læreboka kan elevene hente ekte data rett inn i Python: målinger fra mobilen, posisjonen til romstasjonen, romvær, gravitasjonsbølger og partikkelkollisjoner. Skriptene og lærerveiledningene ligger i et eget repo på GitHub.

Hvert tema har en mappe med kjørbare skript. Lærerveiledningene i repoet har trinnvise instruksjoner, kobling til læreplanen, regneoppgaver og forslag til utvidelser: veiledning for API-eksemplene og veiledning for HR-diagrammet.

Kom i gang

git clone https://github.com/Z0XZ/Fysikk_APIer.git
cd Fysikk_APIer
pip install -r requirements.txt

Noen tjenester krever en gratis API-nøkkel. Det står i lærerveiledningen hvordan dere får den.

Tips til bruk i timen

  • Test skriptene fra skolens nett dagen før. Brannmuren kan blokkere enkelte tjenester.
  • Mange skript lagrer dataene som en CSV-fil. Hent dataene på forhånd og del fila med elevene, hvis nettet er ustabilt.
  • Ekte data har støy, hull og uventede verdier. Det er en god anledning til å snakke om usikkerhet og databehandling.
