Støt mellom vogner i Python

En rød vogn på 0,50 kg kjører inn i en blå vogn på 0,25 kg som står i ro. Farten til begge vognene er logget 40 ganger i sekundet. Bruk Python til å finne ut om bevegelsesmengden og den kinetiske energien er bevart.

Data

Last ned vognstot_smartcart.csv

Fila har tre kolonner: tid i sekunder, farten til den røde vogna og farten til den blå vogna i m/s. Den har desimalpunktum og komma som skilletegn. Dataene er laget med en modell av et støt med magnetstøtfangere, litt friksjon og målestøy, slik at de ligner målinger fra Smart Cart. De er ikke ekte målinger. Bytt gjerne ut fila med deres egne målinger.

Steg 1: Les inn og plott

import numpy as np
import matplotlib.pyplot as plt

data = np.loadtxt("vognstot_smartcart.csv", delimiter=",", skiprows=1)
t = data[:, 0]
v_rod = data[:, 1]
v_bla = data[:, 2]

m_rod = 0.50   # kg
m_bla = 0.25   # kg

plt.plot(t, v_rod, "r.-", label="rød vogn")
plt.plot(t, v_bla, "b.-", label="blå vogn")
plt.xlabel("t / s")
plt.ylabel("v / (m/s)")
plt.legend()
plt.grid()
plt.show()

Steg 2: Bevegelsesmengde og kinetisk energi

p_rod = m_rod * v_rod
p_bla = m_bla * v_bla
p_sum = p_rod + p_bla

ek_sum = 0.5 * m_rod * v_rod**2 + 0.5 * m_bla * v_bla**2

plt.plot(t, p_rod, "r", label="rød")
plt.plot(t, p_bla, "b", label="blå")
plt.plot(t, p_sum, "k--", label="sum")
plt.xlabel("t / s")
plt.ylabel("p / (kg m/s)")
plt.legend()
plt.grid()
plt.show()

Steg 3: Gjennomsnitt før og etter støtet

# Velg tidsrom der farten er omtrent konstant. Se på grafen og juster grensene.
foer = (t >= 0.5) & (t < 0.9)
etter = (t >= 1.2) & (t < 1.6)

p_for = np.mean(p_sum[foer])
p_etter = np.mean(p_sum[etter])
ek_for = np.mean(ek_sum[foer])
ek_etter = np.mean(ek_sum[etter])

print(f"p før:   {p_for:.4f} kg m/s")
print(f"p etter: {p_etter:.4f} kg m/s   ({p_etter / p_for * 100:.1f} %)")
print(f"Ek før:   {ek_for:.4f} J")
print(f"Ek etter: {ek_etter:.4f} J   ({ek_etter / ek_for * 100:.1f} %)")

Oppgaver

Last ned elevark (PDF)

  1. Feilsøk

    Koden i steg 3 gir en feilmelding. Finn feilen og rett den.

  2. Kjør

    Kjør steg 1 og 2. Når skjer støtet, og hvor lenge varer det? Hvordan ser grafen for samlet bevegelsesmengde ut før, under og etter støtet?

  3. Regn

    Kjør steg 3. Hvor mange prosent av bevegelsesmengden og den kinetiske energien er igjen etter støtet?

  4. Forklar

    Bevegelsesmengden ser ut til å avta litt både før og etter støtet. Hvorfor? Hva skjer med resultatet hvis du velger tidsrom som ligger nærmere støtet, for eksempel 0,8–0,975 s og 1,125–1,3 s?

  5. Vurder

    Er støtet elastisk? Er bevegelsesmengden bevart innenfor måleusikkerheten? Begrunn svaret.

  6. Utfordring

    I stedet for gjennomsnitt kan du tilpasse en rett linje til farten før og etter støtet med np.polyfit, og regne ut farten akkurat ved t = 1,05 s. Gjør det, og sammenlign med resultatet fra oppgave 3.

Løsningsforslag og tips til læreren
  1. for er et reservert ord i Python. Gi variablene et annet navn, for eksempel foer og etter.
  2. Støtet skjer ved t ≈ 1,0 s og varer omtrent 0,1 s. Den samlede bevegelsesmengden er nesten konstant hele tiden, mens prød faller og pblå stiger like mye under støtet.
  3. Med 0,5–0,9 s og 1,2–1,6 s: p går fra 0,220 til 0,208 kg m/s (94,5 %), og Ek går fra 0,0485 til 0,0413 J (85 %).
  4. Friksjon bremser vognene hele tiden, så bevegelsesmengden avtar sakte også når vognene ikke støter. Med tidsrom nær støtet blir p-forholdet 98,8 % og Ek-forholdet 91 %. Friksjonen påvirker mindre når tidsrommene ligger nær støtet.
  5. Bevegelsesmengden er bevart innenfor usikkerheten (rundt 1 % avvik nær støtet). Omtrent 9 % av den kinetiske energien går tapt, så støtet er nesten elastisk, men ikke helt. Det passer med magnetstøtfangere.
  6. Eksempel: a, b = np.polyfit(t[foer], v_rod[foer], 1) og så v = a * 1.05 + b. Med tidsrommene 0,5–0,9 s og 1,2–1,6 s gir det p-forhold 102 % og Ek-forhold 94 %. Friksjonen blir regnet bort, men stigningstallene er usikre når man forlenger linjene et stykke, så resultatet blir ikke nødvendigvis bedre.
