Elektrisk felt fra punktladninger

Feltet fra én punktladning er lett å regne ut. Med flere ladninger må vi legge sammen feltvektorene, og det blir fort mye regning. Det klarer Python fint. Til slutt regner vi ut feltet i tusenvis av punkter og tegner feltlinjer.

Steg 1: Feltet i ett punkt

Feltet fra en punktladning q har styrken E = k|q|/r² og peker bort fra en positiv ladning og mot en negativ. Funksjonen felt gir komponentene Ex og Ey. Feltet fra flere ladninger er summen av feltene fra hver ladning. Det kalles superposisjon.

import numpy as np
import matplotlib.pyplot as plt

k = 8.99e9   # N m²/C²

def felt(q, xq, yq, x, y):
    """Elektrisk felt (Ex, Ey) i punktet (x, y) fra ladningen q i punktet (xq, yq)."""
    dx, dy = x - xq, y - yq
    r = np.sqrt(dx**2 + dy**2)
    E = k * q / r**2            # med fortegn: positiv peker bort fra ladningen
    return E * dx / r, E * dy / r

# To ladninger på x-aksen
ladninger = [(4.0e-9, 0.0, 0.0),    # (q i C, x i m, y i m)
             (1.0e-9, 0.30, 0.0)]

def samlet_felt(x, y):
    Ex, Ey = 0.0, 0.0
    for q, xq, yq in ladninger:   # superposisjon: legg sammen feltene
        ex, ey = felt(q, xq, yq, x, y)
        Ex, Ey = Ex + ex, Ey + ey
    return Ex, Ey

Ex, Ey = samlet_felt(0.10, 0.10)
print(f"I punktet (0,10 m, 0,10 m): Ex = {Ex:.0f} N/C, Ey = {Ey:.0f} N/C, E = {np.hypot(Ex, Ey):.0f} N/C")
print(f"Retning: {np.degrees(np.arctan2(Ey, Ex)):.0f} grader over x-aksen")

Steg 2: Hvor er feltet null?

Vi regner ut feltet i 500 punkter på x-aksen mellom ladningene på en gang, og finner punktet der Ex er nærmest null. Den bruker variablene fra stegene over, som cellene i en Jupyter-notatbok.

# Feltet langs x-aksen mellom ladningene
x = np.linspace(0.02, 0.28, 500)
Ex, Ey = samlet_felt(x, 0 * x)

i = np.argmin(np.abs(Ex))
print(f"Feltet er null omtrent ved x = {x[i]:.3f} m")

plt.plot(x, Ex)
plt.axhline(0, color="gray", linewidth=0.8)
plt.xlabel("x / m")
plt.ylabel("$E_x$ / (N/C)")
plt.ylim(-5000, 5000)
plt.grid(True)
plt.show()

Steg 3: Feltlinjer

Vi lager et rutenett med 200 × 200 punkter og regner ut feltet i alle punktene. plt.streamplot tegner linjer som følger feltretningen. Fargen viser feltstyrken på en logaritmisk skala.

# Feltlinjer: regn ut feltet i et rutenett av punkter og tegn med streamplot
ladninger = [(1.0e-9, -0.10, 0.0),
             (-1.0e-9, 0.10, 0.0)]    # en dipol: like store ladninger med motsatt fortegn

X, Y = np.meshgrid(np.linspace(-0.3, 0.3, 200), np.linspace(-0.3, 0.3, 200))
Ex, Ey = samlet_felt(X, Y)
E = np.hypot(Ex, Ey)

plt.streamplot(X, Y, Ex, Ey, density=1.4, color=np.log10(E), cmap="viridis")
for q, xq, yq in ladninger:
    plt.plot(xq, yq, "o", markersize=12, color="tab:red" if q > 0 else "tab:blue")
plt.gca().set_aspect("equal")
plt.xlabel("x / m")
plt.ylabel("y / m")
plt.title("Feltlinjer for en dipol")
plt.show()

Løsningsforslag og tips til læreren
  1. Fra +4,0 nC i origo: r = 0,141 m og E = 1798 N/C, rettet 45° opp mot høyre, altså (1271, 1271) N/C. Fra +1,0 nC i (0,30 m, 0): r = 0,224 m og E = 180 N/C, rettet opp mot venstre, altså (−161, 80) N/C. Summen er (1111, 1352) N/C, E = 1749 N/C, 51° over x-aksen.
  2. Nærmest den lille ladningen. Feltene er like store når 4/x² = 1/(0,30 − x)², altså 2(0,30 − x) = x og x = 0,20 m. Programmet gir 0,200 m.
  3. Mellom ladningene peker begge feltene samme vei, så feltet kan ikke være null der. Nullpunktet ligger utenfor, på siden til den lille ladningen: 4/x² = 1/(x − 0,30)² gir x = 0,60 m.
  4. Feltet er sterkest nær ladningene og mellom dem. I hvert punkt har feltet bare én retning, så det kan bare gå én feltlinje gjennom punktet.
  5. Feltlinjene går ut fra begge ladningene og bøyer bort fra hverandre. Feltet er null midt mellom ladningene.
  6. F = eE = 1,602 · 10⁻¹⁹ C · 1749 N/C = 2,80 · 10⁻¹⁶ N, rettet motsatt av feltet, altså ned mot venstre (231° fra x-aksen).
