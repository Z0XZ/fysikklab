Bil med luftmotstand – numerisk integrasjon

En bil på 1500 kg starter fra ro, og motoren gir en konstant kraft på 1200 N. Luftmotstanden er L = kv² med k = 2,29 kg/m. Jo fortere bilen kjører, desto større blir luftmotstanden, og til slutt når bilen en toppfart.

Steg 1: Simuleringen

import numpy as np
import matplotlib.pyplot as plt

m = 1500     # kg
k = 2.29     # kg/m, luftmotstand L = k v²
F = 1200     # N, kraften fra motoren

n = 6000
t = np.linspace(0, 60, n)
dt = t[1] - t[0]

s = np.zeros(n)
v = np.zeros(n)
a = np.zeros(n)

for i in range(n-1):
    F_sum = F - k*v[i]**2
    a[i] = F_sum/m
    v[i+1] = v[i] + a[i]*dt
    s[i+1] = s[i] + v[i]*dt

print(f"Fart etter 60 s: {v[-1]:.2f} m/s = {v[-1]*3.6:.1f} km/h")
print(f"Strekning etter 60 s: {s[-1]:.0f} m")

Steg 2: Toppfart og eksakt løsning

Ved toppfart er kraftsummen null: F = kvt². For denne bevegelsen finnes det også en eksakt løsning, v(t) = vt · tanh(kvtt/m), som vi kan sammenligne med.

v_t = np.sqrt(F/k)
print(f"Toppfart: {v_t:.2f} m/s = {v_t*3.6:.1f} km/h")
i90 = np.argmax(v >= 0.9*v_t)
print(f"Bilen har 90 % av toppfarten etter {t[i90]:.1f} s")

# Eksakt løsning: v(t) = v_t tanh(k v_t t / m)
v_eksakt = v_t*np.tanh(k*v_t*t/m)
print(f"Største avvik fra eksakt løsning: {np.max(np.abs(v - v_eksakt)):.4f} m/s")

Løsningsforslag og tips til læreren
  1. Toppfarten er 22,9 m/s = 82 km/h. Etter 60 s har bilen 22,2 m/s = 80 km/h, så den har ikke helt nådd toppfarten. Den har kjørt 929 m.
  2. vt = √(F/k) = √(1200/2,29) ≈ 22,9 m/s.
  3. Fartsgrafen flater ut, og akselerasjonen går mot null. Akselerasjonen starter på F/m = 0,80 m/s².
  4. Med dobbel k blir toppfarten √2 ganger mindre: 16,2 m/s = 58 km/h.
  5. P = Fv = 1200 N · 22,9 m/s ≈ 27 kW. Ved konstant fart går hele arbeidet fra motoren til å skyve lufta unna, og ender som indre energi i lufta.
  6. Rullemotstanden er 0,015 · 1500 · 9,81 ≈ 221 N. Da er F − R = kvt², og vt = √(979/2,29) ≈ 20,7 m/s.
